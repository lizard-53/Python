# Python - DataEngine.py
Please find my python script DataEngine.py here. 
Open to constructive feedback to help me improve.

<h4>Project goal:</h4>
A simple data processing tool that can be used to complete data acquisition and processing tasks for businesses.

<h4>Current project state:</h4>
The program reads through the contents of a file and extracts email addresses and UK phone numbers using regex commands stored in regex.json. 

The data is then output as a xlsx file named extracted_data_list.xlsx which should open cleanly into either libre-office calc or MS Excel.

The input data file can either be specified on the command line or through user input when the program is run.
